# Накопитель модернизаций

<RecipesFor id="industrialization_overdrive:upgrade_stacker" />

Накопитель модернизаций предназначен только для мультиблоков с пакетной обработкой. Он вмещает большое количество модернизаций
одного типа в одном предмете, позволяя использовать больше модернизаций, чем помещается в обычный слот.

## Хранение модернизаций

Чтобы сохранить модернизацию, нажмите ею правой кнопкой мыши на накопитель в инвентаре.
Первая добавленная модернизация задаёт тип; далее можно добавлять только модернизации того же типа.

Нажмите <KeyBind id="key.use" /> , держа накопитель в руке, чтобы собрать в него все модернизации сохранённого
типа из инвентаря. Удерживая клавишу приседания, нажмите <KeyBind id="key.use" /> , чтобы извлечь все сохранённые модернизации.

## Использование в механизмах

Нажмите накопителем правой кнопкой мыши по механизму с пакетной обработкой, например
[пиролизной печи](pyrolyse_oven.md) или [многофункционального обрабатывающего массива](multi_processing_array.md), чтобы поместить его в слот модернизаций.
Его также можно установить в этот слот напрямую через интерфейс механизма.

Каждая сохранённая модернизация даёт обычную прибавку ЭЕ/т, но учитывается не более 64 модернизаций на партию. Механизмы с
пакетной обработкой выполняют несколько рецептов одновременно, поэтому накопитель позволяет ускорить их значительно сильнее, чем обычный слот модернизаций.
